### Key Discovery

SWE-bench does NOT use a pre-built Docker image. Instead, it:
- Builds images dynamically for each test instance
- Uses a three-stage build process: base → environment → instance
- Names images like `sweb.base`, `sweb.env`, `sweb.eval.{instance_id}`

Our current implementation assumes we can pull a pre-built image and run evaluation inside it. To properly integrate with SWE-bench, we would need to:
1. Implement the Docker image building process from SWE-bench
2. Use their dockerfiles and build scripts
3. Build the specific environment for each test instance

The error we're seeing (git commit not found) is because we're trying to clone the public Django repo, but SWE-bench would build a Docker image with the exact repository state needed for that test instance.
