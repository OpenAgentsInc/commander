# Claude Code SDK Integration Fix - 18:24

**Issue**: Claude CLI running in interactive mode instead of API mode  
**Solution**: Use Claude Code SDK's non-interactive mode with proper flags

## Key Findings from Claude Code SDK Documentation

### Root Problem

We were using `claude chat` which launches interactive terminal mode. The SDK provides **non-interactive mode** via `claude -p` (print) flag.

### Correct Usage Patterns

#### Single Request (Non-Interactive)

```bash
claude -p "Write a function to calculate Fibonacci numbers"
```

#### With Output Format Control

```bash
claude -p "prompt text" --output-format json
claude -p "prompt text" --output-format streaming-json
```

### Available Output Formats

1. **text** (default): Plain response text
2. **json**: Structured metadata with response
3. **streaming-json**: Emits messages as they arrive (perfect for our use case)

### Step 2: Update Streaming Handler

```typescript
ipcMain.on("claude-code:chat-stream", (event, requestId, params) => {
  const userMessage =
    params.messages?.find((m) => m.role === "user")?.content || "Hello";

  const claudeProcess = spawn(
    claudePath,
    ["-p", userMessage, "--output-format", "streaming-json"],
    {
      stdio: ["pipe", "pipe", "pipe"],
      env: { ...process.env },
    },
  );

  claudeProcess.stdout.on("data", (data) => {
    try {
      const jsonLine = data.toString().trim();
      if (jsonLine) {
        const parsedChunk = JSON.parse(jsonLine);
        // Extract actual content from JSON structure
        const content = parsedChunk.content || parsedChunk.text || jsonLine;
        event.sender.send("claude-code:chat-stream:chunk", requestId, content);
      }
    } catch (parseError) {
      // Fallback to raw text if JSON parsing fails
      const content = data.toString();
      event.sender.send("claude-code:chat-stream:chunk", requestId, content);
    }
  });
});
```

## Enhanced JSON Parsing - 18:36

**Claude Code Response Format**: Rich JSON with message types and tool usage

**Sample response structure**:

```json

{"type":"assistant","message":{"content":[{"type":"text","text":"I'll create a function..."}]}}
{"type":"assistant","message":{"content":[{"type":"tool_use","name":"Read","input":{...}}]}}
```

**Enhanced parsing logic**:

```typescript
if (jsonChunk.type === "assistant" && jsonChunk.message) {
  const message = jsonChunk.message;
  if (message.content && Array.isArray(message.content)) {
    for (const contentPart of message.content) {
      if (contentPart.type === "text" && contentPart.text) {
        // Send actual Claude response text
        event.sender.send(
          "claude-code:chat-stream:chunk",
          requestId,
          contentPart.text,
        );
      } else if (contentPart.type === "tool_use") {
        // Show what tools Claude is using
        const toolInfo = `[Using tool: ${contentPart.name}]`;
        event.sender.send("claude-code:chat-stream:chunk", requestId, toolInfo);
      }
    }
  }
} else if (jsonChunk.type === "system" && jsonChunk.subtype === "init") {
  // Show available tools
  const initInfo = `[Claude Code initialized with tools: ${jsonChunk.tools?.join(", ") || "none"}]`;
  event.sender.send("claude-code:chat-stream:chunk", requestId, initInfo);
}
```
