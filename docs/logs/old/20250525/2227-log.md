# Fixing Claude Code Integration Issue - 2227

## Problem

The telemetry shows that the Claude Code integration is failing with "Utility process exited unexpectedly with code 1". This is because we're trying to use the utilityProcess approach which has module system incompatibilities.

## Root Cause

The utility process cannot execute the wrapper script due to module system incompatibilities. We already discovered this issue and created a working WebSocket bridge solution, but the code is still trying to use the utility process approach.

## Solution

Switch from the utility process approach to the WebSocket bridge approach that we already confirmed works correctly. The bridge service exists at `src/services/claude-bridge-service.js` and uses WebSocket + node-pty to execute Claude CLI commands.
