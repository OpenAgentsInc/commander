# Implementation Log: Disable Multiple Tools for Claude Code CLI

## Date: 2025-05-29 14:22 (Updated)

## Summary
Implemented tool management logic in the Claude Code WebSocket bridge to disable specific tools by default when sending chat history to the Claude Code CLI. The disabled tools include: Task, TodoWrite, TodoRead, NotebookRead, and NotebookEdit.

## Changes Made

### File: `src/main-claude-websocket.ts`

Added tool management logic in the `ipcMain.on("claude-code:chat-stream", ...)` handler after all standard arguments are added to the args array but before sending to the bridge service.

**Location**: Lines 323-371 (after system prompt handling, before logging final args)

**Implementation Details**:
1. Check if `params.allowedTools` is explicitly provided
   - If yes, use it directly with `--allowedTools` flag
   - This respects caller's explicit tool preferences

2. If `allowedTools` is not provided:
   - Initialize `disallowedToolsArray` with any tools from `params.disallowedTools` or empty array
   - Ensure the following tools are added to the disallowed list (case-sensitive):
     - "Task"
     - "TodoWrite"
     - "TodoRead"
     - "NotebookRead"
     - "NotebookEdit"
   - Add `--disallowedTools` flag with the combined list

3. Enhanced logging:
   - Console log showing all disabled tools with improved formatting
   - Console log showing total count of disabled tools
   - Telemetry logging (if available) with event details including:
     - Event name: 'claude_code_tools_disabled'
     - List of disabled tools
     - Session ID
     - Timestamp

## Technical Details

- The `ClaudeExecParams` interface already includes optional `allowedTools?: string[]` and `disallowedTools?: string[]` fields
- The current implementation in `useCoderChat.ts` doesn't pass these fields, so the default behavior will kick in
- Tool names are case-sensitive in Claude CLI - "Task" is the correct casing
- The implementation ensures backward compatibility - if a caller explicitly provides `allowedTools`, it takes precedence

## Result

The following tools will now be disabled by default for all Claude Code CLI interactions via the streaming WebSocket bridge:
- Task
- TodoWrite
- TodoRead
- NotebookRead
- NotebookEdit

These restrictions can be overridden by explicitly providing an `allowedTools` parameter from the renderer process.
