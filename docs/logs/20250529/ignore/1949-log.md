# JSON Marshal Fix Implementation Log

## Date: 2025-05-29
## Time: 19:49

## Problem
The Claude Code CLI was encountering a JSON unmarshaling error when using the "Write" tool:
```
json: cannot unmarshal number into Go struct field WriteInput.content of type string
```

This indicated that the Go-based server expected a string for the `content` field but received a number.

## Root Causes Identified
1. The system prompt was being skipped (line with `console.log('skipping system pormpt ez')`)
2. The application was providing a hardcoded default system prompt instead of letting Claude Code use its built-in prompt

## Fixes Applied

### 1. Fixed System Prompt Passing in main-claude-websocket.ts
- **File**: `src/main-claude-websocket.ts`
- **Line**: 323-328
- **Change**: Removed the line that was skipping the system prompt and properly implemented the conditional passing of the system prompt to Claude CLI
- **Before**:
  ```javascript
  if (systemPromptContent) {
    console.log('skipping system pormpt ez')
    // args.push("--system-prompt", systemPromptContent);
  }
  ```
- **After**:
  ```javascript
  if (systemPromptContent && systemPromptContent.trim() !== "") {
    args.push("--system-prompt", systemPromptContent);
    console.log(`[Main Process] Using system prompt (first 100 chars): ${systemPromptContent.substring(0, 100)}...`);
  } else {
    console.log("[Main Process] No system prompt provided by params, or it's empty. Claude CLI will use its default system prompt.");
  }
  ```

### 2. Removed Hardcoded System Prompts in useCoderChat.ts
- **File**: `src/hooks/coder/useCoderChat.ts`
- **Changes**: 
  1. Modified the system prompt extraction logic to only pass a system prompt if it's not the default placeholder
  2. Removed all hardcoded "You are Claude Code, a helpful AI coding assistant." system messages
  3. Updated the message initialization to start with empty arrays instead of including a system message

- **Key Changes**:
  - Line 43-48: Changed initial messages from including a system message to returning an empty array
  - Line 82-88: Updated clearMessages to use empty array instead of including system message
  - Line 144-149: Updated newMessagesState initialization to empty array
  - Line 379-401: Modified to conditionally include systemPrompt only when it's not the default

## Rationale
By removing the hardcoded system prompts and letting Claude Code use its built-in default system prompt, we:
1. Allow Claude Code's comprehensive default prompt (which includes proper tool usage instructions) to be used
2. Avoid overriding the well-crafted default with a minimal placeholder
3. Fix the JSON marshaling error by ensuring proper type handling instructions are included in the default prompt
