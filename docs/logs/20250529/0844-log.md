# Implementation: Preserve Interleaved Order of Text and Tool Calls

## Problem
Assistant messages with text and tool calls are not being saved/rehydrated in the correct interleaved order. Currently all text appears first, followed by all tool calls.

## Solution
1. Save assistant message content as structured JSON array preserving order
2. Update CoderPane to parse and reconstruct messages in correct order

## Implementation Steps

### Step 1: Examine current accumulation logic in main-claude-websocket.ts

Found that `accumulatedContent` array is already collecting all content parts in order at line 402:
```typescript
accumulatedContent = accumulatedContent.concat(assistantMessage.content);
```

### Step 2: Update message saving to use structured content

Modified the assistant message saving in both 'claude_stream_done' and 'exit' cases to save the structured array:

```typescript
const assistantDbMessage = {
  id: assistantMessageId,
  session_id: sessionId,
  role: "assistant",
  content: JSON.stringify(accumulatedContent), // Store structured content
  tool_calls_json: toolCalls.length > 0 ? JSON.stringify(toolCalls) : undefined,
  timestamp: Math.floor(Date.now() / 1000),
};
```

Also updated the placeholder message to start with an empty array: `content: "[]"`

### Step 3: Update CoderPane.tsx to handle structured content

Updated the `loadMessagesForSessionInternal` function in CoderPane.tsx to handle the new structured content format:

1. Added logic to check if assistant message content is a JSON array (new format)
2. If it is, parse and reconstruct parts in the exact order they appear
3. For each `tool_use` part, immediately add the corresponding tool result if available
4. Falls back to old logic for backward compatibility

The key change:
```typescript
if (dbMsg.role === 'assistant') {
  // Check if content is structured JSON array (new format)
  let successfullyParsedStructuredContent = false;
  if (dbMsg.content) {
    try {
      const structuredContent = JSON.parse(dbMsg.content);
      if (Array.isArray(structuredContent)) {
        // Process each part in order, preserving interleaving
        for (const rawPart of structuredContent) {
          if (rawPart.type === 'text') {
            parts.push({ type: 'text', text: rawPart.text });
          } else if (rawPart.type === 'tool_use') {
            parts.push({ type: 'tool_call', ... });
            // Immediately add tool result if available
            const execution = toolExecutionMap.get(rawPart.id);
            if (execution) {
              parts.push({ type: 'tool_result', ... });
            }
          }
        }
        successfullyParsedStructuredContent = true;
      }
    } catch (e) {
      // Fallback to old format
    }
  }
}
```
