## Infinite Loop Fix

Fixed an infinite loop caused by the useEffect in useCoderChat updating pane content on every render:

1. **useCoderChat.ts**: 
   - Changed to only update pane content when sessionId actually changes (not on every render)
   - Added condition: `if (determinedSessionId && determinedSessionId !== initialSessionId)`

2. **Reduced logging spam**:
   - PaneManager: Removed per-render logging
   - CoderPane: Moved logging to useEffect that only runs on mount
   - updatePaneContent: Only log for coder panes

The infinite loop was happening because:
1. useCoderChat updates pane content
2. This triggers a re-render
3. Re-render runs useEffect again
4. useEffect updates pane content again
5. Repeat infinitely

Now it only updates when the sessionId actually changes.

## Toggle Restoration Fix

Fixed the toggle restoration logic in toggleAllCoderPanes.ts:

1. **Issue**: The function was immediately creating a new pane when no visible coder panes existed, without checking closedPanePositions first.

2. **Fix**: Restructured the logic to:
   - If visible coder panes exist → hide them
   - If no visible coder panes → check closedPanePositions for restorable panes
   - Only create new pane if no restorable panes found

3. **Key changes**:
   - Simplified the main conditional from `if (hasActiveCoderPane || visibleCoderPanes.length > 0)` to just `if (visibleCoderPanes.length > 0)`
   - Moved the restoration logic to the else block where it will actually be executed
   - Added detailed logging to track what's in closedPanePositions

The flow is now:
1. Toggle off: Save panes to closedPanePositions with content and shouldRestore=true
2. Toggle on: Check closedPanePositions for coder panes and restore them with their saved sessionId and position
