# v0.0.5 - Claude Code Integration & UI Enhancements

This is an **alpha pre-release** version for developers.

This release introduces a groundbreaking integration with Claude Code CLI, bringing AI-powered coding assistance directly into Commander. With the new Coder Pane, developers can leverage Claude's advanced capabilities for code generation, debugging, and analysis while maintaining full conversation history. Additionally, significant UI improvements, database integration, and a flexible feature flag system set the foundation for controlled feature rollouts.

### Features

-   **NEW: Claude Code CLI Integration:**
    -   **Coder Pane:** A dedicated chat interface for AI-powered coding assistance with Claude Code.
    -   **External Bridge Service:** Robust architecture using WebSocket bridge for reliable Claude CLI communication.
    -   **Tool Use Visualization:** See exactly what tools Claude is using (file operations, searches, etc.) with collapsible displays.
    -   **Session Persistence:** All coding conversations are saved to a local PGLite database.
    -   **Streaming Responses:** Real-time display of Claude's responses as they're generated.
    -   **Multi-Instance Support:** Open multiple Coder Panes with independent sessions.
    -   **Resilient Sessions:** Claude processes survive Electron restarts during long-running tasks.

-   **NEW: PGLite Database Integration:**
    -   Embedded PostgreSQL database for local data persistence.
    -   Full-featured SQL support with transactions and queries.
    -   Session and message history stored locally.
    -   Tool execution tracking and replay.

-   **NEW: Feature Flag System:**
    -   Granular control over which features are enabled.
    -   Configuration-based feature toggles for safe rollouts.
    -   Supports AI providers, UI panes, and experimental features.
    -   Ghost UI elements maintain consistent layouts when features are disabled.

-   **NEW: Previous Chats UI:**
    -   Browse and restore previous AI chat sessions.
    -   Integrated with Agent Chat Pane for Ollama/DVM conversations.
    -   Search and filter chat history.

-   **Enhanced UI/UX:**
    -   **Dropdown Menu System:** Panes now support title bar menus (implemented in Coder Pane).
    -   **ProseMirror Editor:** Rich text input with multi-line support (Shift+Enter for new lines).
    -   **Auto-scroll Improvements:** Better handling of scrolling during streaming responses.
    -   **Copy Button:** Hover-activated copy functionality for messages.
    -   **Keyboard Shortcuts:** Escape to close panes, Cmd/Ctrl+Click for new pane instances.

-   **Developer Experience:**
    -   **Vite Configuration:** Fixed file watching issues that caused unwanted rebuilds.
    -   **IPC Architecture:** Improved communication between renderer and main processes.
    -   **Error Handling:** Better error messages and recovery for failed operations.

-   **Existing Features Maintained:**
    -   NIP-90 Data Vending Machines (both consumer and provider).
    -   NIP-28 public chat channels.
    -   Hand tracking for UI interaction.
    -   Spark wallet integration for Bitcoin Lightning payments.

### Installing

No binaries yet. Run it locally following our [local development instructions.](https://github.com/OpenAgentsInc/commander#running-a-dev-build)

**Key Requirements for this release:**
-   **Claude Code CLI:** Must be installed separately via `npm install -g @anthropic-ai/claude-code`. Run `claude auth` to authenticate.
-   **Ollama:** Required for local model inference if using non-Claude AI features. Default model is `gemma3:1b`.
-   **Spark Wallet:** Required for NIP-90 DVM payments and provider functionality.
-   **Nostr Identity:** Needed for NIP-90 interactions and NIP-28 chats.

**Feature Flags:** This release uses a feature flag system. By default, only Claude Code, Coder Pane, and Hand Tracking are enabled. Modify configuration to enable additional features.

## Breaking Changes

-   The default configuration now uses feature flags. Some features from v0.0.4 may be disabled by default.
-   Database schema has been updated. First run may take longer as tables are created.

## Known Issues

-   Vite file watching is disabled in development mode when using Claude Code to prevent interruptions.
-   Some UI elements may flicker during initial render due to feature flag loading.
-   Claude Code sessions require manual cancellation if the process hangs.
